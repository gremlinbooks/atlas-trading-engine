# Session Log - 2026-03-22

## Objective
- Improve consistency and profitability on `AUD_USD M15` while reducing live loss-tail risk.

## Major Changes Implemented
- Added `no_intent` override framework (feature-flagged and tunable):
  - `STRATEGY_NO_INTENT_OVERRIDE_*`
- Added hour-specific strict entry mode (feature-flagged and tunable):
  - `STRATEGY_HOUR_STRICT_*`
  - In strict hours, entries can require stronger components (`cross` or `continuation`) and can reduce size.
- Added live intrabar hard-loss guard in evaluator:
  - `STRATEGY_INTRABAR_LOSS_EXIT_ENABLED`
  - `STRATEGY_INTRABAR_LOSS_EXIT_PIPS`
  - Purpose: exit open losing trades before M15 candle close when threshold is breached.
- Added per-decision sizing support path used by strict/override modes (`entry_units_multiplier` metadata).

## Key A/B Findings
- Blocking UTC `17,18` significantly improved results versus prior baseline.
- `no_intent` override (broad) underperformed in tested windows; current recommendation is `disabled`.
- March 1-21 strict-hour test:
  - Control (`strict off`): PF `< 1` and negative PnL.
  - Strict mode (`hours 6,7,11,20`, reduced size): PF improved to `1.1669`, PnL improved, DD reduced.
